# Legacy: the original ESP8266 cartridge

Everything in this folder comes from the project this repo was forked from, [Staacks/wifi-game-boy-cartridge](https://github.com/Staacks/wifi-game-boy-cartridge) (there.oughta.be), and is kept unchanged for reference. None of it is used by the Rev B cartridge.

| Folder | What | License |
|---|---|---|
| `esp8266/` | ESP8266 Arduino sketches for the original demos (serial, wiki, stream, color-stream) | GPL-3 |
| `gb/` | Game Boy side of those demos (RGBDS, needs rgbasm 0.5.2) | GPL-3 |
| `python/` | PC-side streaming scripts | GPL-3 |
| `pcb/` | Original cartridge PCB (KiCad 8) | GPL-3 |
| `3dprint/` | Original 3D-printed shell, sized for that PCB, not checked against Rev B | CC-BY-NC-SA (derived from DomesticHacks' cartridge model) |
